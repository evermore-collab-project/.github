**Preserving memories, stories, and voices for generations to come.**

Evermore is a digital memorial platform that allows families to create personalised memorial webpages for loved ones and pets. Each memorial can be accessed through a unique QR code, making it easy to revisit and share treasured memories.

## Features

- **Personalised Memorials** — Dedicated webpages celebrating an individual's life.
- **Photos & Videos** — Preserve and share meaningful moments.
- **Voice Recordings** — Keep cherished voices and stories alive.
- **Family Contributions** — Allow family and friends to share memories.
- **QR Code Access** — Link physical memorials directly to digital pages.
- **Memorial Requests** — Submit requests to create new memorials.

## Our Goal

To provide families with a lasting digital space where memories can be preserved, shared, and passed down through generations.

## Project Status

Currently in development. The project is being developed as a prototype, with a focus on UI design, usability, and core functionality.
